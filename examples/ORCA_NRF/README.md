# ORCA NRF example

NRF radio carrier example for FreeWili 2.

![Assembled ORCA NRF example board](../../assets/nrf.png)

Open [ORCA_NRF.kicad_pro](ORCA_NRF.kicad_pro) in KiCad to inspect the
[schematic](ORCA_NRF.kicad_sch) and [PCB](ORCA_NRF.kicad_pcb).

The photograph shows the assembled example board. The existing PCB's 3D
model references include absolute paths; see the [repository notes](../../README.md#orca_nrf-example)
when opening its 3D view on another machine.
